# Joomla Playground links

Each link opens a new Joomla Playground in the language of the tour, with the tour installed; the tour starts by itself.
Open each link in a new browser tab.

The short links load the blueprint from the playground's GitHub Pages site; the files `<language>/<name>.link.txt`
hold a link with the whole blueprint in it, which works without that site.
