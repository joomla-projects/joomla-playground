    Test a pull request of Joomla

    The site opens without the patch. Apply patch in the toolbar applies it and shows the same page again, now with the changes; Revert patch takes them out, so before and after are one click apart. The playground starts the Joomla version of the pull request's branch.

    As a link: …/joomla-playground/?pr=48831, with &url= for the page. Changes to JavaScript or CSS are not built, so only PHP, template, language and XML changes show. See the open pull requests.

      Make your own link

      Parameters set up a new playground; combine them with &.

      • A site in Dutch ?language=nl-NL
      • PHP 8.5 ?php=8.5
      • Open the front end ?url=/index.php
      • Start logged out ?login=no
      • Install an extension ?extension=<zip URL>
      • Your own blueprint ?blueprint-url=<JSON URL>

      A blueprint is a small JSON file with the steps to set up a site: install extensions, sample data, languages, articles, settings. See setting up a playground with a link.

      Everything runs in your browser: PHP is compiled to WebAssembly, and the site and its database live in the tab. Nothing is sent to a server. Use a recent Chrome, Edge or other Chromium browser. Source and documentation on GitHub.
